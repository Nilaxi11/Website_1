# Responsive Website Landing Page

A simple and responsive landing page built using HTML, CSS, and Bootstrap.  
This project focuses on clean UI design, mobile responsiveness, and beginner-friendly frontend structure.

# About The Project

This project is a frontend website created with basic web technologies including HTML, CSS, and Bootstrap.  
The goal was to build a responsive and modern-looking website layout that works smoothly across different screen sizes.

It includes:
- Responsive sections
- Clean navigation bar
- Modern UI layout
- Bootstrap components
- Mobile-friendly design
